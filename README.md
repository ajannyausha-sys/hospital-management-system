# Carewell – Hospital Management System

An interactive front-end demo: ward bed map, patient registry, appointment booking and doctor duty roster. Data is stored in the browser (localStorage), so no backend is needed.

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy
- **GitHub Pages:** repo Settings → Pages → Deploy from branch → `main` / root.
- **Netlify:** Add new site → Import from Git (no build command, publish directory `.`).
- **Vercel:** Add New Project → import the repo (Framework preset: Other).
